The in-game minimap ships on.

**This release overwrites existing `plugins/tpf2_bigmap.cfg`, including user edits, on installation, upgrade and repair.** Close the game before installing. It shares the proxy and plugin host with TpF2 Multiplayer 0.6.1; installing either package updates both.

- **Minimap on by default** (`minimap=1`). 0.5.0 introduced the native-rendered minimap for maps too large for the game's own, with company colours and names when TpF2 Multiplayer is installed, but shipped it off, and every install of the package reset a hand-edited `minimap=1` back to off. Set `minimap=0` in `plugins/tpf2_bigmap.cfg` to remove the map button again.

Everything else is 0.5.1 (the 32 GB machine fix).

# docs/history

Milestone reports and status notes from the project's first phase (M1 through M10,
2026-07 to 2026-08), plus the original p2p plan. They describe the code as it was
then: `mod/mp_bridge_1`, the injector, `tools/autotest.ps1` and friends now live
under `archive/`, and the retired build scripts they mention are in git history
(`git show v0.4.0:<path>`). For the current state read `../SLICE_STATUS.md` and
`../STRICT_LOCKSTEP_PLAN.md`.

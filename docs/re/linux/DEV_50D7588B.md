## Not ported / decision

The corrected native company tint remains unavailable. Missing prerequisites
are proven station/depot/window entity and live-engine provenance, safe owner
lookup including StationGroup pool/first-station semantics, stale-class cleanup,
and exception/lifetime-safe relays across all relevant branches and world
changes. A style helper alone cannot implement those contracts. Future native
tagging must append `mpWinCoN`/`mpCoN`; selectors retain `!`.

No new native address or offset is used by code and no patch is installed.
Existing visibility and permission hooks remain intact. No live selector or
rendered-colour validation is claimed; neither Steam nor the game was started.

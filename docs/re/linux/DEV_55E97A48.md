The named reflection/type-signature anchors, 0xb8 Stop stride, vector layout,

sections 1–2. UpdateLine receives the return object in rdi, engine in rsi,
entity in edx and Line pointer in rcx. Decode precedes its consuming move.
The libstdc++ vectors remain three pointers; Windows's 0xa8 Stop stride is
not used. Float values are serialized with %.9g in field order, including
negative/infinite values; NaN is refused. Removing policy ceilings introduces
no new layout assumption. Ordered/aligned begin/end/cap and readable storage
are still required. Refusals log the failing field and stop number.

## Steam persona

`nm -D` on the game's adjacent `libsteam_api.so` proves these C exports:

- `SteamAPI_GetHSteamUser`, `0x1cf10`;
- `SteamAPI_SteamFriends_v017`, `0x203f0`;
- `SteamAPI_ISteamFriends_GetPersonaName`, `0x20410`.

Disassembly of 0x203f0: `48 8d 3d 69 30 03 00` loads the context in rdi;
`e8 20 9e ff ff` at 0x203fb calls SteamInternal_ContextInit; `48 8b 00`
at 0x20400 returns the interface in rax. At 0x20410 the bytes
`48 8b 07 48 8b 00 ff e0` dispatch through the interface in rdi, returning
its const char pointer in rax (SysV). We call the named C export, never a
hardcoded vtable slot or address. RTLD_NOLOAD refuses to load/initialize Steam;
missing exports, a zero user or a null interface/name preserve the fallback.
The library handle stays held while the name is copied. Mock exports exercise
availability, refresh and persisted-name behavior without any game process.

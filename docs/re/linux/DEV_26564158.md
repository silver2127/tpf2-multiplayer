# Native outward terrain lookup: dev 26564158

This change uses the existing AddTile/grid contract documented in
[DEV_2B4FD093.md](DEV_2B4FD093.md) and
[DEV_5FD49A24.md](DEV_5FD49A24.md). No engine address, hook, struct offset,
SysV forwarding signature, byte guard or ownership rule changes.

Fresh read-only verification against the lab ELF confirms build-id
`3a0e156390b0e6f1e372051c24802c8493ae454a` and all 39 manifest sites.
Fresh disassembly at `0xcf73f2..0xcf7440` confirms terrain+0x18 is loaded
(`49 8b 77 18`), nx at grid+8 is used in the coordinate calculation, records
come from grid+0x10 (`48 8b 46 10`), two LEAs multiply by 40, and the entity
is stored at record+0 (`45 89 2c 24`). The existing vector-at-record+8
contract remains unchanged; no new offsets were inferred.

The mod-owned thread-local hint now stores the last hit. It resets to n-1 on
new grids or load generations, then searches +1, -1, +2, -2, wrapping at the
ends. Native code stops at floor(n/2) and checks the original hint last. This
removes upstream's redundant final outward step while preserving the order
of each record's first visit. Every miss and repeated hit probes exactly n
records; a singleton probes once. The existing generation invalidation
covers surviving workers and reused grid addresses.

Production AddTile accumulates calls reaching FindRecord and their probes,
using relaxed atomic additions once per lookup. LoadHook resets them;
PassDone reports the ratio when releasing the sidecar, guarding a zero
count. This measures sidecar lookups, not all stock AddTile calls. Neither
these counters nor the cursor publish engine memory.

Native fixtures cover all start/target pairs for sizes 1 through 9 with exact
probe counts, ascending and descending traversal, alternating workers,
load-generation invalidation, null vectors, missing entities and grid changes.
The fake full-load path checks production counters and restored tile data.
No game was launched: this algorithm introduces no new live ABI contract.
Prior live ownership/lifetime gaps remain; sidecars stay experimental and
default off. Probe counts from fixtures are not game timings.

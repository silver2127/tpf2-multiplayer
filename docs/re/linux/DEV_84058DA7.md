## Finding and correction

Upstream already implements the recycler in native Linux. Its five Vulkan
functions use the existing `InitDeviceDetour`, but `FindDeviceSlot` stops at
`vkQueueSubmit`, offset `0xae0`. The reset function is beyond that boundary,
so the incoming code cannot find all five slots in this ELF.

The shared Vulkan function-name strings anchor `vk::DispatchLoaderDynamic::init`
at `0x35167d0`. The caller at `0x35096e9` is `e8 e2 d0 00 00`; immediately
before it, rdi is loaded with dispatcher `0x5b3d740` and rsi with VkDevice.
The callee saves rdi into rbx and rsi into r12. Each lookup loads the name
into rsi, moves r12 into rdi and calls `[rbx+0x798]` (vkGetDeviceProcAddr).
Its pointer result is stored from rax into the dispatcher. This establishes
the SysV ABI directly, without Windows offsets or C++ object translations.

| Vulkan function | Name load | Result store | Dispatcher offset |
|---|---|---|---|
| vkAllocateDescriptorSets | 0x3516840 | 0x351685e | 0x28 |
| vkDestroyDescriptorPool | 0x3517772 | 0x3517793 | 0x5a8 |
| vkDestroyDescriptorSetLayout | 0x3517789 | 0x35177aa | 0x5b0 |
| vkFreeDescriptorSets | 0x3517a1f | 0x3517a40 | 0x6e8 |
| vkResetDescriptorPool | 0x35181e1 | 0x3518202 | 0xb28 |

The recycler now searches through `0xb28` inclusive, after checking all 40
bytes at `0x35181e1`:

```
48 8d 35 83 b1 a3 00 4c 89 e7 48 89 83 20 0b 00 00
ff 93 98 07 00 00 48 8d 35 82 b1 a3 00 4c 89 e7
48 89 83 28 0b 00 00
```

The first LEA resolves `vkResetDescriptorPool` at `0x3f5336b`. The store
at +10 belongs to the preceding lookup; the final store is the reset result.
The guard spans complete instructions. No new executable patch is installed:
the existing call redirection verifies its original target. The expanded
scan is used only for descriptor hooks, requires each driver pointer to be
non-null and unique, and writes none of the five slots if any check fails.
Existing menu build-id gating and successful render-suppression gating remain.
Opaque Vulkan handles and the vendored PFN signatures define wrapper arguments;
no engine-owned struct layout or entity lifetime is newly assumed.

## Validation and limits

`tools/linux/verify_descriptor_dispatch_elf.py` checks the build-id, existing
call bytes, source guard bytes, all five name-string references, indirect
calls and result stores against the supplied ELF. `overlay_cache` exercises
the formerly missed reset slot, duplicate/null refusal and mutation of each
guard byte. The incoming fake-driver recycler tests cover reuse, partial
allocations, refused allocations, free/reset/destroy and layout invalidation.

A launch with the candidate libraries and dedicated recycling enabled was
attempted through `tools/sandbox/tpf2mp-lab run native`. It stopped before
exec with `bwrap: setting up uid map: Permission denied`. No game process,
Vulkan device, live dispatcher, gdb probe, loaded save or allocation heartbeat
was observed. Thus activation and mmap/munmap reductions are not live-validated
here; upstream performance numbers are not local measurements. Both lab
payload directories were restored and compared recursively with their backups.
Evidence: job `meta/live/launch.txt`, `restoration.txt`, archived actor logs/data;
static outputs and build logs: `.git/port-84058da/`.

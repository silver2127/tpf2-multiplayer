## Static evidence

Rechecked the existing [line layout evidence](SLICE_LINES.md) against the
actual ELF. The upstream decoder's three ordinary vectors at stop offsets
`0x50/0x68/0x80` must **not** be copied into Linux.

- `0x228b377`: `48 c7 85 90 fc ff ff 50 00 00 00` writes the Stop member
  pointer `0x50`. The registration call at `0x228b414` passes it to the
  Stop binding. The exported function signatures identify this member as
  `Line::StopConfig Stop::*`.
- Stop copy constructor loop `0xb83190` copies two libstdc++ bit vectors.
  At `0xb83363..0xb83376` it computes
  `([src+0x60]-[src+0x50])*8 + u32[src+0x68] - u32[src+0x58]`.
  Allocation at `0xb835c0..0xb835cb` rounds the bit count up by 63, shifts
  right 6 and then left 3: 64-bit storage words. The next bit-vector
  storage begins at `+0x78`, with the float container at `+0xa0`.
- Stop-vector destructor `0xaa43f0` frees `+0xa0`, `+0x78`, `+0x50`,
  `+0x38`, `+0x10`. At `0xaa4459`, bytes `48 81 c3 b8 00 00 00`
  advance the Stop pointer by `0xb8` (Windows uses `0xa8`).
- `xrefs.csv` anchors the StopConfig name at `0x228b5a6`, in the
  component registration function `0x228ab50`. `0x228b5b0` writes its
  `maxLoad` member pointer `0x50`; `0x228b5cf` calls `0x2285690`.
  In that constructor, `maxLoad`, `unload`, `load` literals are referenced
  at `0x22856b7`, `0x228573c`, `0x228578d`. It stores the member pointer
  at metatable `+0xa8`, next to the maxLoad name at `+0xb0`.
- `funcsig.csv` at `0x229a5a0` identifies load and unload as
  `sol::property_wrapper` getters taking `const Line::StopConfig&` and
  setters taking `Line::StopConfig&, const std::vector<int>&`.
  maxLoad is `IdVector<CargoTypeId, float> Line::StopConfig::*`.
  Thus the Lua integer containers are not the two in-memory containers.
  Also inspected the metatable setup `0x229a5a0..0x229c1ce`; this did not
  establish the complete getter/setter conversion.

SysV arguments at registration `0x228b5cf`: rdi is the destination binding
object (`r15+0x10`), rsi the type name, rdx the address of the member pointer.
These are registration arguments, not a live command ABI probe. Existing
CreateLine/UpdateLine interception and its byte guards are unchanged.

indices, per-cargo integer flags or packed integer words, including their
ordering/empty behavior; prove property write-back from the shared
`lineApplyCargo` on real userdata. A plain Lua table fixture cannot settle
whether modifying a getter-returned container persists. Do not substitute
the vehicle autoLoad word encoder merely because its backing storage is
also a bit vector. Upstream's Windows offsets are explicitly marked inferred.

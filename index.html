TpF2 Multiplayer

Real multiplayer for Transport Fever 2. Several players build in one world at the same time: the roads, railways, stations, depots, vehicles and lines one player makes appear for everyone, applied at the same moment of the simulation on every computer.

Download the installer Source code on GitHub

What it does

  • Build together

    Everything a player builds or changes is sent to everyone and applied at the same simulation step on every machine, including the player's own.

  • One company or several

    Play a single shared company, or separate companies with their own money on the same map.

  • Host or join from the title menu

    A Multiplayer panel on the game's title menu hosts a game, joins with a code, or lists public games. A dedicated relay works when nobody can open a port.

  • Stays in sync

    Everyone starts from the same save, and a detector keeps comparing the worlds so a difference is noticed at once.

How it works

Transport Fever 2 has no network code, so TpF2 Multiplayer adds lockstep multiplayer from outside the game. A small forwarding DLL loads the project's DLLs when the game starts: one captures each command a player issues and holds it back, one carries commands between the game and a separate lobby program, and one draws the Multiplayer panel. A game-script mod stamps every command with a future simulation step and replays it on every machine at that step. The lobby handles connecting players, NAT traversal, encryption and sending the save. The architecture document has the details.

Download

Get TpF2Multiplayer.msi from the latest release on GitHub, close the game, and run it. Every player in a session needs the same version. Requirements: Transport Fever 2 on Steam for Windows.

Each release lists the installer's SHA-256 checksum in its notes. To uninstall, use Settings → Apps → TpF2 Multiplayer → Uninstall; the game's original files are put back.

Code signing policy

This project has applied to the SignPath Foundation for free code signing of its Windows installer and DLLs. Once approved, releases will carry: Free code signing provided by SignPath.io, certificate by SignPath Foundation. Until then, releases are unsigned; check the SHA-256 checksum in the release notes.

Signed files will be built only from this project's public source repository, by its automated build. Committers and approvers: the project maintainer (silver2127). Every signing request is approved by the maintainer.

Privacy

TpF2 Multiplayer only sends data over the network for the multiplayer features a player uses. The privacy policy lists exactly what is sent, where, and what the project's servers keep.

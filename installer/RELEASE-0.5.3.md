Speed voting, desync checks on every map, and hot-join robustness

- Speed voting: the session runs at the average of everyone's speed votes, rounded to 0.05. Pressing a speed button, in the game's clock or in the Multiplayer window's new speed row, is your vote; it does not change your own game's speed by itself. `/speed <x>` in the chat overrides the votes until the next vote. Only the host pauses.
- Big maps are checked again. The desync hash was switched off entirely above vanilla's largest size (96 x 96 tiles), because a 224-tile world cost 3.0-3.5 s per stamp. The interval now follows the hash's measured cost: it starts from the edge count and the leader moves every game along a ladder (12 ... 1536 game units) with a stamped `HASHEVERY`, so a 224-tile map hashes about once every ten minutes at 1x instead of never. The vehicle-drift check turns off for good once a world has more than 200 vehicles, saved with the world.
- Far behind, your actions are off. More than 15 game units behind the fastest game, anything you build, buy or edit is cancelled until you are back within 2 units, and the Multiplayer window says so. A line you create is kept and made once you have caught up.
- Bridge protocol 5: events are sized to their text (63-1,086 bytes instead of a flat 1,086). Not wire-compatible with earlier versions -- every player must be on this release.
- The automatic command delay no longer spikes after every autosave: round trips timed across a freeze are ignored, and the delay steps down only with a margin to spare (256 changes and a 3.0 peak in one logged session, 2 changes and 1.2 after).
- In-game lobby panel: opening it from inside a loaded game dropped the frame rate to 10-15 FPS and its buttons did nothing. The panel was composited over a blurred read-back of every frame (40-65 ms a frame) and the mouse hook never captured in-game clicks. It is now an opaque sheet composed only when it changes, and in-game clicks reach it, so the close button works.
- Mods: accepting a mod download while the save transfer was still open was dropped, so the host waited 90 s, treated it as a no and failed the transfer. The consent now counts.
- Lobby: after one resync, every later joiner was rejected with "This recovery session has a fixed player roster" for the rest of that lobby's life, including in a new game. The gate now reads the recovery's phase.
- Natural Town Growth: the wrapped update runs once per virtual second on a simulation-time grid, anchored at load/init, so a game catching up at 4x grows towns identically to one at 1x (1x, 4x, 16x and a jittery frame rate now produce identical capacity writes offline). Every hash mismatch now logs which lanes differ, not only a declared desync, and `dump_egeo=1` in `tpf2_slice.cfg` writes each instance's exact edge list per stamp for diffing.
- Chat: long messages wrap in the in-game chat.

Close the game before installing, update all peers (the bridge protocol changed), and restart both instances.

Validation: offline, 24 test scripts including the new speed-vote, drift-cap, hash-cadence, big-map, far-behind, packet-size, delay-noise, lobby-readiness and deterministic-script (1x/4x/16x/jitter) checks; in game on a two-instance rig, the in-game panel fix, mod acceptance, chat wrapping, catch-up on a large map and big-map hashing. Not resolved in this release: one town-development desync after a hot join into a running world was observed with the Natural Town Growth fix already in place and was recovered with a resync -- the new per-mismatch lane detail and edge dump exist to pin it; and a single station replay refused by a joiner (engine `seed` assertion) rolled the host's copy back and left bought vehicles without a line, which is open.
